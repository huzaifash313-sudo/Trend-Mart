--------------------------------------------------------------------------------
1. PLATFORM OVERVIEW
--------------------------------------------------------------------------------

TrendsMart ek hyper-local multi-vendor marketplace hai jahan:
  • Customers nearby shops browse karte hain aur WhatsApp par order bhejte hain.
  • Merchants apni dukaan, products, delivery area, aur orders manage karte hain.
  • Super-Admin platform ko approve/moderate/analytics se control karta hai.

Guest users bina signup ke browse kar sakte hain. Checkout / order pe authentication
aur phone verification apply hota hai.


--------------------------------------------------------------------------------
2. USER ROLES & ACCESS
--------------------------------------------------------------------------------

2.1 Guest (Bina login)
  • Homepage, search, shop pages, categories, products freely browse
  • Cart localStorage mein save (items add/remove)
  • Wishlist (local), FAQ, legal pages, support form
  • Signup/login ke baghair checkout pe phone OTP flow

2.2 Customer
  • Email + password signup/login
  • Email verification (OTP / confirmation link)
  • Account portal: profile, addresses, orders, wishlist, settings
  • Checkout pe phone OTP (pehli dafa; baad mein skip ho sakta hai)
  • "Become a Merchant" se merchant ban sakte hain

2.3 Merchant
  • Separate merchant signup role YA customer → become-merchant form
  • Store create (name, category, city/location, WhatsApp, logo, banner)
  • Full merchant dashboard (products, orders, settings, analytics, etc.)
  • Store live/hide toggle (is_live)

2.4 Super-Admin
  • /admin/* routes
  • Merchant approve/reject/suspend
  • Platform metrics, categories, promo ads review
  • Support tickets, audit logs

Role resolution: user_roles table + JWT metadata + shop ownership fallback
(middleware + authService).


--------------------------------------------------------------------------------
3. AUTHENTICATION & SECURITY
--------------------------------------------------------------------------------

3.1 Signup / Login
  • Email + password
  • Role choose: Customer ya Merchant
  • Terms & Privacy checkbox (mandatory)
  • Routes: /signup, /login, /auth/*

3.2 Email Verification
  • Confirmation email + OTP modal
  • Resend verification
  • Unverified users → /auth/verify-notice
  • Callback: /auth/callback (production URL use hota hai, localhost nahi)

3.3 Phone OTP (Checkout)
  • Order place karte waqt phone verify
  • Pakistan numbers (+92) normalize
  • Agar Supabase SMS provider na ho to graceful degrade (order block nahi)

3.4 Security
  • Middleware route protection (role-based)
  • Rate limiting (Redis/Upstash optional, memory fallback)
  • Security headers + CSP
  • Environment variable security audit on build
  • RLS policies on Supabase tables
